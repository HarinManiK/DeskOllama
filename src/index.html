⚙️ Settings & Parameters Explained
num_ctx (Context Length)

Controls the maximum token context window (e.g. 4096, 8192, 16384). Larger context windows allow models to remember longer conversations, requiring more RAM/VRAM.

temperature

Controls randomness. Low values (0.1–0.3) make outputs deterministic and focused; high values (0.7–1.0) increase creativity and variety.

top_p (Nucleus Sampling)

Considers only tokens with cumulative probability reaching top_p. Lower values make responses tighter and less random.

keep_alive

Defines how long the model remains loaded in memory (RAM/GPU) after your last query (e.g. 5m, 1h, or -1 for persistent loading).

Thinking Mode (Chain-of-Thought)

Toggles internal reasoning blocks for reasoning models (e.g. DeepSeek-R1, Qwen 2.5 Coder), allowing you to expand or hide thought processes.

System Prompts & Personas

Defines custom rules, roles, and instructions that govern how the model answers every message.
